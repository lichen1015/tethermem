The problem

One memory policy cannot serve two opposite needs.

Subject identity needs long-range access. Scene progression needs recency. Applying one frame-level memory policy to both creates the familiar identity–progression trade-off.

The real choice is not “remember or forget.” It is which query should read which part of memory.
RF

Rolling-Forcing

A short rolling context can preserve local continuity while repeatedly returning to the opening view.
